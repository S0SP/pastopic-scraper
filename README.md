# PastTopic Paper Scraper

Scrapes Cambridge IGCSE & A-Level question papers from pastopic.com across **all boards and all subjects** — including Question Papers, Mark Schemes, Examiner Reports, Grade Thresholds.

Files are stored in the companion HF Dataset and available as a ZIP download.
